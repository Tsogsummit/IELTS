# BandPrep Mock Test

Independent IELTS-style mock test platform with student, grader, admin, and super admin roles.

## Run Locally

```bash
npm start
```

Open `http://localhost:3002`.

No dependency installation is required. The backend uses Node.js built-in modules and stores local development data in `server/data/db.json`. The browser UI uses local React runtime files in `public/vendor`.

If `npm` is not on your PATH but Homebrew Node is installed, run:

```bash
/opt/homebrew/bin/node server/index.js
```

Main implementation:

- `server/index.js`: HTTP server, auth, RBAC, seed import, tests, submissions, grading, reports.
- `public/app.js`: React UI pages and reusable components.
- `public/styles.css`: responsive academic dashboard styling.

Classes must begin with `11`, so 9th grade and test rows are skipped. Imported passwords are hashed immediately, and students are marked `mustChangePassword: true`.

| --- | --- | --- |
| Super Admin | `superadmin` | `SuperAdmin123` |
| Admin | `admin` | `Admin1234` |
| Grader | `grader` | `Grader1234` |

## Add Tests And Questions

Use an admin or super admin account:

1. Open **Admin Dashboard**.
2. Go to **Test Management** or **Question Bank**.
3. Create tests, add Listening/Reading questions, upload an audio URL, or add passages.

For development, you can also edit `server/data/db.json` after the first run. Restart the server after manual edits.

## Bulk Student Import

Admin Dashboard -> Student Import supports pasted CSV with:

```csv
name,class,email,phone,parentName
```

The app previews the rows, generates usernames/passwords, detects duplicates, creates accounts, exports credentials CSV, and renders printable login cards.

## Security Notes

- Passwords are hashed with PBKDF2 SHA-512.
- Temporary passwords are only stored in the generation batch and can be regenerated by admins.
- Sessions are HTTP-only cookies.
- Login requests are rate limited.
- Role-based access control protects API routes.
- Students can only view their own results/submissions.
- Graders can only view assigned Writing/Speaking submissions.
